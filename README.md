# 塞曼效应交互式模拟器

> **Hg I 546.1 nm 反常塞曼效应虚拟实验台**
> 零依赖 · 纯前端 · 可离线运行 · 无需构建

一个用于大学物理实验教学的塞曼效应虚拟实验台。它不止于演示「谱线分裂」这一现象，而是把**磁场 → 能级分裂 → 谱线分裂 → 干涉环分裂 → 反算玻尔磁子**的完整因果链做成可交互、可测量、可验证的闭环：学生能在其中按真实实验协议采数据、拟合出 μ_B，并与 CODATA 标准值对照。

## 特性

- **物理内核严谨** —— 546.1 nm 的真实跃迁是 `6s7s ³S₁ → 6s6p ³P₂`，上下能级 Landé g 值不等（2.0 vs 1.5），属**反常塞曼效应**，分裂为 **9 条**而非 3 条。相对强度 `1:3:6:3:4:3:6:3:1` 由总角动量 J² 数值对角化独立求得。
- **两种观察方向** —— 垂直于 B 观察得π + σ 共 9 条线偏振分量；平行于 B 观察只有 σ⁺/σ⁻ 两组圆偏振，插入 λ/4 波片 + 检偏片可完全分离两组。
- **偏振选择定则可验证** —— 偏振片0–360° 连续可调，实时显示马吕斯定律透射率。0° 只留 π 线、90° 只留 σ 线，中间角度连续过渡。
- **可做的真实测量** —— 两步法测量协议：先由零场相邻两级环直径反解干涉级次，再测分裂谱线对的环直径，由 ΔD²–B 线性拟合反算 μ_B。
- **可分辨的干涉环** —— Fabry–Perot 参数经过混叠判据优化（FSR = 5cm⁻¹对 1.87 cm⁻¹ 的塞曼跨度，约 9 个清晰环），不是装饰性插图。
- **学生 / 教师双模式** —— 学生模式隐藏理论值与拟合结果，先自行测量；教师模式揭晓斜率、R²、μ_B 与相对误差。

## 3. 侧栏控件详解

### 3.1 磁场控制

| 控件 | 范围 | 说明 |
|---|---|---|
| 磁场 `B` 滑块 | 0 → 1.10 T，步长 0.005 T | 主控量，直接决定分裂程度 |
| 线圈电流 `I` 滑块 | 0 → 6.50 A，步长 0.02 A | 与 B 联动：**B = 1.30·tanh(I / 5.20)**（软磁芯磁饱和） |
| `归零` / `最大场` | — | 一键置 0 / 置满场（I = 6.50 A → B = 1.1028 T） |

两个滑块双向同步：拖动 B 会按反函数 `I = 5.20·artanh(B/1.30)` 求出对应电流，拖动 I 则正向算 B。改动 B 或 I 本身不影响已完成的标定，但第 2 步的每个测量点都必须在**当前显示的 B** 下采集。

> 两个滑块的量程是**互相导出**的：`B_max = 1.30·tanh(I_max/5.20) = 1.1028 T`。因此把 B 拖到尽头所需的电流恰好是 `I_max`，不会出现「B 滑块要求 6.46 A、而 I 滑块最大只有 6.00 A」这种两个读数互相矛盾的中间态。

### 3.2 观察条件

#### 观察方向

| 模式 | 物理后果 |
|---|---|
| **⊥ B**（默认） | 9 条分量全部存在：π 线偏振 ∥ B，σ 线偏振 ⊥ B。**第 ④ 步的测量协议固定在此模式下进行** |
| **∥ B** | 只有 σ⁺、σ⁻ 两组圆偏振（各 3 条），π 线不辐射 → 共 6 条 |

#### 偏振片（0–360° 连续可调）

- 拖动转盘、滑块或点击预设按钮均可调角度；预设从 0° 到 315° 每 45° 一个，另加「移除」。
- 角度定义：**0° = 透振方向 ∥ B**，90° = ⊥ B。线偏振片具有 180° 周期，故 0°/180° 等价、90°/270° 等价，但界面保留完整 0–360° 以符合直觉。
- 遵循马吕斯定律，透射率随角度连续变化：
  - π 线（偏振 ∥ B）：`w_π = cos²θ`
  - σ 线（偏振 ⊥ B）：`w_σ = sin²θ`
- 因此：**0°/180° 只保留 π 线，90°/270° 只保留 σ 线**，中间角度 9 条均可见但亮度连续变化。转盘下方两条进度条实时显示 π 与 σ 的透射率。
- **沿 B 观察时** σ 线是圆偏振，线偏振片对其恒减半 → 50%，与角度无关（提示文字会明确指出这一点）。

#### 四分之一波片（λ/4 片）

- **仅在「∥ B 观察」下可用**。⊥ B 观察时光本来就是线偏振，波片只会把它变成椭圆偏振，毫无分选意义，因此控件被禁用并显示「不适用（需沿 B 观察）」。
- 快轴角 φ 范围 0–180°（同样 180° 周期），可拖动转盘或用预设：`0°`（纯 σ⁺）、`22.5°`（各半）、`45°`（纯 σ⁻）、`取出`。
- 物理原理：σ 组是圆偏振，波片把它转换为**线偏振，方向相对快轴转过 2φ**；再由后置偏振片（检偏片）分选：

  ```
  w(σ⁺) = cos²(θ − 2φ)
  w(σ⁻) = sin²(θ − 2φ)
  ```

  两组偏振方向正好相差 90°，可完全分离。
- **「一键配置：波片 + 检偏片」**按钮是最常用的入口：自动置检偏片 0°、波片 0°，即纯 σ⁺。由此把波片从 0° 转到 45°，就能连续演示「纯 σ⁺ → 各半 → 纯 σ⁻」的全过程。
- 若只插入波片而无后置偏振片，两组仍重叠，此时界面会给出「无法分选」的明确提示，而不是错误地显示 100%/100%。

## 5. 物理模型（内置参数与公式）

### 5.1 谱线与能级

**6s7s ³S₁ → 6s6p ³P₂**（这是 546.1 nm 实际对应的跃迁，注意不是 ³P₀）。

| 能级 | 波数 / cm⁻¹ | J | L | S | g |
|---|---|---|---|---|---|
| 6s7s ³S₁（上） | 62350.325 | 1 | 0 | 1 | 2.000 |
| 6s6p ³P₂（下） | 44042.909 | 2 | 1 | 1 | 1.500 |
| 6s6p ³P₀ | 37644.982 | 0 | 1 | 1 | 0 |
| 6s6p ³P₁ | 39412.237 | 1 | 1 | 1 | 1.486 |

- ν₀ = 18307.416 cm⁻¹ → λ₀ = 546.227 nm（真空值；空气中 546.07 nm）
- **g_上 ≠ g_下 → 反常塞曼效应 → 分裂为 9 条而非 3 条**

### 5.2 九条分量

允许跃迁由选择定则与 CG 系数确定，位移因子

```
δ = g_u m_u − g_l m_l     （以洛伦兹单位 L 为单位，1 L = μ_B B/hc = 0.46686·B cm⁻¹）
```

按**从内环到外环**编号为 1 → 9（波长越长 → cos θ 越大 → θ 越小 → 环半径越小，故红移分量在内侧）：

| 线序号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| δ | −2 | −1.5 | −1 | −0.5 | 0 | +0.5 | +1 | +1.5 | +2 |
| 偏振 | σ⁻ | σ⁻ | σ⁻ | π | π | π | σ⁺ | σ⁺ | σ⁺ |
| 相对强度 | 1 | 3 | 6 | 3 | 4 | 3 | 6 | 3 | 1 |

> CG 平方系数由 `cg_exact.py` 在**固定 M 子空间**内对角化 J² 独立生成，每个固定 m_u 切片精确求和为 1；脚本以 assert 硬校验 7 个 1×1 教科书值，任一处不符即以非零码退出，并实读 `src/physics.js` 交叉核对 `CG2` 表。**不要手写 Wigner 3j 公式**，前因子极易出错。
>
> **符号约定**：正 δ 对应**更高波数**（波长更短、半径更大），故蓝移分量在外圈、红移分量在内圈。`splitDiameter()` 直接复用 `components()` 的波长结果，因此 δ 与环的对应只有一个真相源——环上标注的 δ 必然落在实际绘制的那个环上。`test_physics.js` 对这一点有专门的不变式检查。

### 5.3 Fabry–Perot 环

共振条件 `m λ = 2 n d cosθ`，Airy 透射

```
T = 1 / (1 + ℱ sin²(π d cosθ / λ))
```

- 轴上最高级次 `m_axis = 2nd/λ`
- 环半径 `r_k = f·tanθ_k`，其中 `cosθ_k = m_k/m_axis`
- `d = 1.0 mm` → FSR = 5.00 cm⁻¹；塞曼总跨度 1T 时仅 1.87 cm⁻¹ → **2.7 倍余量，不混叠**
- 视场 4.0° 时视场内约 9 个零场环

> 两个条件必须同时满足：FSR ≫ 塞曼跨度（防混叠），且视场内环数足够（防信息不足）。`d = 1.0 mm`、θ_max = 4.0° 是自洽点。默认配置下 `m_axis = 3662`，视场内级次范围 3654 – 3662。

### 5.4 可见性判定

- 偏振片：`w_π = cos²θ`，`w_σ = sin²θ`（⊥ B 观察）；圆偏振恒为 0.5（∥ B 观察）
- 波片 + 检偏片：`w(σ⁺) = cos²(θ − 2φ)`，`w(σ⁻) = sin²(θ − 2φ)`
- 权重 `≥ 1×10⁻³` 才计为可见

## 6. 典型实验流程

### 6.1 观察分裂现象

1. 保持「⊥ B」观察、偏振片移除
2. 拖动 `B` 滑块从 0 增到 0.5 – 1.0 T，观察：能级图分裂 → 光谱由单线展为 9 条 → FP 环图由单环分裂为同心多环
3. 在①中核对箭头强度比是否为 `1:3:6:3:4:3:6:3:1`

### 6.2 验证偏振选择定则

| 偏振片角度 | 预期结果 |
|---|---|
| 0° / 180° | 只剩 π 线（第 4、5、6 条） |
| 90° / 270° | 只剩 σ 线（第 1–3、7–9 条） |
| 45° 等中间角 | 9 条全在，亮度按 cos²θ / sin²θ 连续变化 |

### 6.3 分离 σ⁺ 与 σ⁻

1. 观察方向切到「∥ B」→ 只剩 6 条，π 线消失
2. 插入 λ/4 片（点「一键配置」自动配好检偏片）

## 7. ④ 实验测量协议

> **前置条件**：观察方向 = ⊥ B，偏振片移除，λ/4 片取出。此模式下 9 条分量全可见，1–9 的线序号才有意义。
>
> 这一条件由程序**强制**：几何不符时面板标题变黄告警、三个测量按钮被禁用；
> 若在已有数据点时改变观察方向或偏振片/波片状态，已记录的数据点会全部作废
> （1–9 的线序号只在协议几何下成立，混用会导致拟合出错误结果）。
> 测量本身始终在协议几何下进行（`M.MEAS_GEOM`），不会跟随界面上正在预览的
> 其他几何——所以不会出现「用沿 B 观察的图去测 ⊥ B 的量」这种错误。

### 7.1 第 1 步：定标 —— 测 B = 0 时的两个参考环直径

**原理**：相邻两级次满足

```
u = λ₀ / (2 n d) = cosθ_k − cosθ_{k−1}
```

其中 `cosθ = f / √(f² + r²)`。由于 u 是两个极其接近的余弦之差，解析式对读数极敏感，程序改为**在视场范围内枚举候选 k 并做双环半径相对残差拟合**，取最优者。

**操作**：

1. 确认 B = 0（`归零` 按钮）
2. 选参考级次 `k`（滑块 3655–3660，默认 **3658**；面板实时给出第 2 步的级次 m = k − 1、视场内环数、组内相邻线间距与环宽之比「分辨率」）
3. 点「测量 D_k 与 D_{k−1}」

**输出**：`D_k`、`D_{k−1}`、反解出的 `u`、级次 `k`、拟合残差。完成后面板标记✓，第 2 步的 m 被锁定。

### 7.2 第 2 步：测一对对称谱线的环直径

**原理**：关于 δ = 0 对称的两条谱线（δ = ±δ₀），其环直径平方差严格正比于 B：

```
ΔD² = D外² − D内² = 16 f² K² ν₀ δ₀ · μ_B · B / (h c),  其中 K = 2 n d / m
```

故 `μ_B = ΔD² · h c / (16 f² K² ν₀ δ₀ B)`。

**可选谱线对**：

| 选项 | δ₀ | 特点 |
|---|---|---|
| 第 4 / 6 条（π 线对） | 0.5 L | 两环间距较小，低场下可能未完全分辨 |
| **第 3 / 7 条（σ 线对，默认）** | 1.0 L | 间距大，推荐 |

**操作**：

1. 选谱线对（切换会清空已有数据）
2. 调 `B` 到目标值
3. 点「记录本点」

程序在每条线的**理论半径附近**做窄窗搜索并要求匹配比相邻环更近，避免误取邻线或邻级次的环。成功后表格新增一行：`B / D外 / D内 / ΔD² / μ_B`。

### 7.3 数据处理

- **至少 2 个不同 B 值**才能给出拟合结果
- 拟合 `ΔD²–B` 为**过原点单参数斜率** `slope = Σ(B·y)/Σ(B²)`（关系严格线性）
- `μ_B = slope · h c / (16 f² K² ν₀ δ₀)`，斜率单位 cm²/T
- 同时给出 R²（对无约束最佳拟合的残差比）、斜率标准误 → μ_B 不确定度、各点 μ_B 的平均值与标准差、与 CODATA 值的相对误差（|误差| < 3% 判为「测量合理」）

**「自动扫描 0 → 1.05 T」**按钮会一次性在 `0.50 / 0.65 / 0.80 / 0.95 / 1.05 T` 五个点完成测量并拟合，比手动快得多。低场下若个别点未成功，界面以**内联提示**报告（不弹窗），并说明「低场下相邻谱线未完全分辨属正常现象」。

「清空」重置参考级次与全部数据。

### 7.4 典型回归结果

以默认配置（k = 3658 → m = 3657）执行自动扫描，5 个场点全部成功：

| 谱线对 | δ₀ | 成功点数 | 斜率 / cm²·T⁻¹ | R² | μ_B / J·T⁻¹ | 相对误差 |
|---|---|---|---|---|---|---|
| **σ 对（第 3 / 7 条，默认）** | 1.0 L | 5 / 5 | 0.25509 | 0.99977 | 9.2489×10⁻²⁴ | **−0.27 %** |
| π 对（第 4 / 6 条） | 0.5 L | 4 / 5 | 0.13015 | 0.99057 | 9.4375×10⁻²⁴ | **+1.76 %** |

第 1 步反解结果：`u = λ₀/(2nd) = 2.730377×10⁻⁴`，拟合残差 `3.5×10⁻⁷`。

> π 线对在 0.50 T 处失败并非故障：环间距只有 σ 对的一半，低场下未完全分辨。这正是默认推荐 σ 线对的原因。

残余偏差主要来自两处，与真实实验同量级：

1. 第 1 步的读数误差 —— u 是两个接近余弦之差，对环位读数极敏感
2. 分裂环未完全分辨

## 8. 常见问题

**Q：改了视场 θ_max 或参考级次 k，为什么数据被清空了？**
因为可见级次范围随之改变，第 1 步必须重做。这是刻意的失效保护，不是 bug。

**Q：为什么 λ/4 片在「⊥ B」观察下是灰的？**
该方向下光已是线偏振，波片只会产生椭圆偏振，没有分选意义。沿 B 观察圆偏振时波片才起作用。

**Q：只插了波片、没放检偏片，为什么两组仍是 50%/50%？**
没有后置偏振片就无法区分两组圆偏振。界面会显示「无法分选」提示，请点「一键配置」补上检偏片。

**Q：0° 和 180° 有什么区别？**
线偏振片透振方向具有 180° 周期，二者物理等价；界面保留 0–360° 仅为符合直觉。同理 90° 与 270°。

**Q：干涉环看起来挤在一起 / 分不开九条？**
降低 `B` 会让环靠得更拢。提高磁场，或把光谱仪分辨率调小（如 0.02 L），或改用第 3 / 7 条 σ 线对（间距是 π 对的两倍）。

**Q：把 `d` 调大到 6 mm 之类会怎样？**
FSR = 1/(2nd) 会小于塞曼总跨度，相邻干涉级次**混叠**，环图将出现假的交替结构。保持 d ≤ 2 mm。

**Q：第 1 步提示「找不到与这两个环直径吻合的相邻级次」？**
通常是所选 `k` 不在当前视场内。换一个 k，或增大视场 θ_max。

**Q：自动扫描有几点失败？**
低场（0.5 T 附近）相邻谱线可能未完全分辨，属预期现象。提高磁场下限或改用 σ 线对即可。

### 9.2 在 Node 中直接使用物理内核

`src/physics.js` 同时支持浏览器与 Node：

```js
const P = require('./src/physics.js');

P.components(0.9);            // 9 条分量：δ、波长、偏振、强度
P.splitDiameter(3657, 3, 0.9) // 第 3 条线在 m=3657、0.9T 下的环直径（mm）
P.muBFromDiameterPair(27.635, 27.216, 0.9, 3657, 1.0);  // → 9.27401e-24
P.maxOrder();                 // 3662
P.minVisibleOrder(4 * Math.PI / 180);  // 3654
```

主要导出：`components`、`applyGeometry`、`polariserWeight`、`qwpWeight`、`sigmaGroups`、`airy`、`ringRadius`、`splitDiameter`、`zeroFieldDiameter`、`orderFromTwoDiameters`、`muBFromDiameterPair`、`diameterPairSlopeScale`、`linfit`、`fieldFromCurrent`、`currentFromField`，以及常量 `MU_B`、`NU0`、`LAMBDA0_NM`、`G_UP`、`G_LO`、`FP`、`MAGNET`、`SYMMETRIC_PAIRS`、`LINE_INDEX_DELTA`。

> `fieldFromCurrent(I)` 与 `currentFromField(B)` 互为反函数，`MAGNET.B_max` / `MAGNET.I_max` 由同一条标定曲线导出。改动电磁铁参数时三者必须同步，否则侧栏两个滑块会给出互相矛盾的读数。

#### 已废弃的导出（勿在新代码中使用）

`ringRadiusSqVsB`、`ringSlope`、`muBFromSlope`、`OUTER_D` 属于**旧版「跟踪单个环的 r²–B」协议**。
该模型会留下一个很大的、与 B 无关的几何项，必须先扣除才能反解 μ_B，因此已被
现行两步法取代。这四个符号仅为对照参考而保留，源码中已标注 `@deprecated`。
当前协议请用 `SYMMETRIC_PAIRS` + `muBFromDiameterPair` / `diameterPairSlopeScale`。

> 顺带修正：旧注释称被跟踪的红移分量是「最外环」，实际红移分量（δ<0）
> 因波长更长、cos θ 更大而位于**最内环**——与 §5.2 的环序号约定一致。
